# IAM Lab 1 — Security Assessment Reports

This folder contains written documentation from a hands-on Microsoft Entra ID employee offboarding security assessment conducted in a training environment.

The documentation includes:

- **Final Security Assessment Report:** Assessment scope, findings, remediation actions, audit verification, risk assessment, and security recommendations.
- **Investigation Findings:** Detailed records of the identity and access management investigation.
- **Lab Completion Record:** Summary of completed remediation activities and remaining assessment limitations.

**Disclaimer:** This project uses a fictional organization and simulated employee offboarding scenario. All documentation is intended for cybersecurity training and professional portfolio demonstration.
